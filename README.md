# Electromagnetic Intelligence
Admissible localized quantities, positive measures, and primitive relations determine an information field. An external query changes its incident source, and the resulting query-restricted variational response performs attention.

Every finite active information field admits an exact realization in an invariant transverse sector of ideal Maxwell evolution. A modal isometry preserves its action, source coupling, energy, attention response, and retarded response. Information-field dynamics can therefore be realized electromagnetically without identifying information with electromagnetism.
